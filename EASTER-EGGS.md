# Easter eggs du portfolio

Liste des easter eggs cachés dans le site. Chut, c'est secret !

---

## Liste

### 1. Konami Code

- **Déclencheur** : Taper ↑ ↑ ↓ ↓ ← → ← → B A au clavier
- **Effet** : Confettis + flip du site + Matrix rain + modale "GG !"

### 2. Logo cliquable secret

- **Déclencheur** : Cliquer 7 fois rapidement sur "Justine BLIN" dans le header
- **Effet** : Le texte tourne sur lui-même avec un effet arc-en-ciel pendant 4 secondes

### 3. Mode disco

- **Déclencheur** : Taper "disco" au clavier
- **Effet** : Le fond du site change de couleur en boucle, les éléments rebondissent (5 secondes)

### 4. Mode terminal

- **Déclencheur** : Taper "terminal" au clavier
- **Effet** : Fond noir, texte vert monospace, curseur clignotant (6 secondes)

### 5. Retour vers le futur

- **Déclencheur** : Cliquer sur l'année dans le footer
- **Effet** : L'année défile de 2026 à 1990 puis revient, avec une modale "Retour vers le futur !"

### 6. Gravité inversée

- **Déclencheur** : Taper "gravity" au clavier
- **Effet** : Toute la page s'envole vers le haut puis retombe (2.5 secondes)

### 7. Mode pirate

- **Déclencheur** : Taper "arrr" au clavier
- **Effet** : Drapeau pirate + les onglets du menu deviennent des termes pirates (5 secondes)

### 8. Pluie d'emojis

- **Déclencheur** : Double-cliquer sur un titre h1
- **Effet** : 60 emojis tombent du haut de l'écran

### 9. Snake

- **Déclencheur** : Taper "snake" au clavier
- **Effet** : Un jeu de Snake jouable en overlay (flèches pour jouer, Échap pour quitter)

### 10. Thème arc-en-ciel

- **Déclencheur** : Taper "rainbow" au clavier
- **Effet** : La couleur principale du site alterne entre toutes les couleurs de l'arc-en-ciel (10 secondes)

### 11. Message console

- **Déclencheur** : Ouvrir la console développeur (F12)
- **Effet** : ASCII art "JB" et message secret avec indices

### 12. Page 404 interactive

- **Déclencheur** : Aller sur une page inexistante
- **Effet** : Les chiffres du "404" sont attrapables à la souris (drag & drop avec retour élastique)

### 13. Jeu du dino (page 404)

- **Déclencheur** : Aller sur une page inexistante
- **Effet** : Un jeu du dinosaure jouable (Espace/clic pour sauter, éviter les cactus)
